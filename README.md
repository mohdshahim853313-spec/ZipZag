# ZipZag - Logic Grid Path Puzzle Game

ZipZag is an addictive, procedural logic grid path puzzle game. Connect numbered checkpoints in ascending numerical order while covering 100% of the cells on the grid with a single, continuous Hamiltonian path!

## Features
- **500 Progressive Solvable Levels** with difficulty chapters and tiers.
- **Electric Indigo & Violet Theme** with crisp, responsive SVG path drawing.
- **Unique Procedural & Fixed Puzzles** mathematically verified for Hamiltonian paths.
- **Smart Controls**: Undo, Smart Hint, Auto-Solve, and Procedural Level Generator.
- **Daily Streak Tracker** & Personal Best Leaderboard.
- **Web Audio Sound Effects**: Dynamic procedural sound synthesis.
- **Full Touch & Keyboard Navigation**: Mouse drag, touch gesture, and arrow/WASD key support.

## Run Locally

**Prerequisites:** Node.js (v18+)

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.
